Amazon Order Automation with Power Automate

I run a small personalised gifts business. Every order meant copying details from an email into my stock sheet by hand, so I automated it.

Business: Creative Paradigms LtdTools: Power Automate, Gmail, Google Sheets

The Challenge

Each Amazon order arrives as an email. I was copying the order number, products, personalisation, quantities and dispatch date into a Google Sheet by hand, then updating stock. On a busy day this took real time, and a single typo could mean the wrong product or a stock count that did not match the shelf.

How the Flow Works

  • Trigger. The flow starts when a new Amazon order email arrives.
  • Extract. It reads the email and pulls out the details it needs, such as the dispatch-by date.
  • Split items. One order can contain several products, so the flow splits the order into a list of separate items.
  • Build rows. For each item it builds one row in the exact format my sheet expects.
  • Insert. It adds each row to my Google inventory sheet, with a short delay between rows so the sheet keeps up.

Formulas in the sheet then update stock levels, so I can see straight away what needs reordering.

The Result

Add the time saved, e.g. "about X minutes a day" or "X hours a month", and how many orders it has handled. Fewer mistakes, and stock levels I can trust.

Why It Matters

This is a pattern most businesses have. Data arrives in one place, it needs to end up in another, and a person sits in the middle copying it. I enjoy finding those gaps and closing them.
